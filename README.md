# Meshtastic-chat

Автономный LoRa-чат для двух (и более) человек на платах **WiFi LoRa 32 V4
(ESP32-S3 + SX1262)**, работающих от повербанков и подключаемых к телефонам
по Bluetooth LE.

Прошивка используется **штатная Meshtastic** — она уже умеет всё, что нужно:
BLE-подключение к телефону, официальное приложение с интерфейсом чата,
mesh-маршрутизацию с автоматическим ретранслированием пакетов через соседние
узлы (пригодится, если в будущем добавите ещё устройства), шифрование
каналов. Переписывать это с нуля нет смысла — риск багов и потери сообщений
в лесу того не стоит.

Этот репозиторий — набор скриптов, которые **автоматически и одинаково**
настраивают ваши устройства: регион LoRa, приватный зашифрованный канал
(чтобы вашу переписку не видели чужие Meshtastic-узлы поблизости), имена
узлов и роль в сети. Вручную через приложение это тоже можно сделать, но
скриптами — быстрее и без риска разойтись в настройках между двумя платами.

## Как это работает

1. На оба устройства прошивается стандартная прошивка Meshtastic (Web Flasher).
2. Скрипт `generate_channel.py` один раз генерирует случайный ключ шифрования
   и создаёт приватный канал `team-chat`.
3. Скрипт `provision_device.py` применяет этот канал + имя + регион на
   каждое устройство по очереди (через USB).
4. На телефоны ставится официальное приложение Meshtastic, подключается по
   Bluetooth к своей плате — и в приложении сразу появляется чат в канале
   `team-chat`.
5. Устройство кладётся в карман/рюкзак, подключается к повербанку через
   USB-C, и просто работает — сообщения идут по LoRa напрямую между двумя
   платами. Если появится третья плата в радиусе действия любой из двух —
   мгновенно заработает ретрансляция (mesh), без каких-либо действий с
   вашей стороны.

## 1. Прошивка устройств

Если на платах ещё нет прошивки Meshtastic (либо стоит старая/сбитая) —
подключите плату по USB-C к компьютеру с Chrome/Edge и прошейте через
официальный веб-флешер: https://flasher.meshtastic.org/
Выберите вариант платы, максимально близкий к вашей (ESP32-S3, семейство
"WiFi LoRa 32" / heltec-подобные с SX1262 — уточните в списке поддерживаемых
плат по документации к вашей конкретной ревизии V4). Если ваша модель платы
не входит в стандартный список flasher'а, читайте инструкцию продавца платы
— обычно поставляется ссылка на подходящий вариант прошивки (device target)
для этого конкретного клона.

## 2. Настройка окружения для скриптов

Понадобится Python 3.9+ на любом одном компьютере (настраивать оба
устройства можно с одной машины по очереди через USB).

```bash
python3 -m venv .venv
source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

## 3. Общие настройки команды

```bash
cp config/team.example.yaml config/team.yaml
```

Откройте `config/team.yaml` и поправьте под себя:

- `region` — регион LoRa, должен соответствовать стране использования
  (для РФ — `RU`). Список: https://meshtastic.org/docs/configuration/region-by-country/
- `channel_name`, `modem_preset` — по умолчанию разумные значения, менять не
  обязательно.
- `devices` — впишите себя и коллегу (`id`, `long_name`, `short_name`).
  При необходимости позже добавите сюда третьего участника.

Этот файл не содержит секретов и в git не коммитится, потому что личные имена
— тоже ваше дело, но если хотите держать его в репозитории для истории —
можно убрать из `.gitignore`.

## 4. Генерация приватного канала

Выполняется **один раз**:

```bash
python3 scripts/generate_channel.py
```

Скрипт создаст `config/channel.secret.yaml` со случайным ключом шифрования
и ссылкой канала. Этот файл — ваш общий секретный ключ для чата, храните
его так же аккуратно, как пароль, и **не публикуйте**. Он уже добавлен в
`.gitignore`, чтобы случайно не закоммитить его в репозиторий.

## 5. Настройка каждого устройства

Подключите первую плату по USB-C и узнайте её порт:

```bash
python3 scripts/list_devices.py
```

Затем примените настройки (используйте `id`, который вписали в
`config/team.yaml`):

```bash
python3 scripts/provision_device.py --device alice --port /dev/ttyUSB0
```

Отключите первую плату, подключите вторую, повторите с другим `--device`:

```bash
python3 scripts/provision_device.py --device bob --port /dev/ttyUSB0
```

Каждый запуск устанавливает имя узла, применяет общий приватный канал и
роль `CLIENT`, после чего перезагружает устройство.

## 6. Подключение телефонов

1. Установите приложение **Meshtastic** (Google Play / App Store) на оба
   телефона.
2. Включите Bluetooth, в приложении нажмите "Добавить устройство" /
   "+" и выберите свою плату по имени (`short_name` из `team.yaml`).
3. После подключения в приложении появится канал `team-chat` — это и есть
   ваш общий чат. Второй телефон делает то же самое со своей платой.
4. Пишите сообщения — они уходят по LoRa напрямую между устройствами
   (обычно несколько км в прямой видимости за городом, меньше в лесу/среди
   построек).

## Работа от повербанка

Платы подключаются к повербанку обычным USB-C кабелем как к источнику
питания — дополнительной настройки не требуется, Meshtastic сам определяет
питание от USB/пауэрбанка и не уходит в глубокий сон, чтобы не пропускать
сообщения. Автономность зависит от ёмкости повербанка и текущего
`modem_preset` — `LONG_FAST` из коробки уже сбалансирован по энергопотреблению.

## Расширение до mesh-сети (3+ устройств)

Просто повторите шаг 5 для нового устройства, добавив его в `devices` в
`config/team.yaml` — оно получит тот же приватный канал и автоматически
станет частью сети. Роль по умолчанию `CLIENT` уже участвует в
ретрансляции чужих сообщений. Если хотите поставить отдельное
стационарное устройство именно для увеличения покрытия (например, на
возвышенности, без своего телефона), поменяйте ему `role` в `team.yaml` на
`ROUTER_CLIENT` (шлёт и свои, и чужие сообщения) или `REPEATER` (только
ретранслирует, экономичнее по эфиру) перед провижининг.

## Безопасность

- Канал зашифрован PSK (AES-256) из `channel.secret.yaml` — без этого ключа
  прочитать сообщения нельзя, даже находясь рядом и слушая эфир.
- Не публикуйте `config/channel.secret.yaml` и ссылку канала
  (`channel_url`) — тот, у кого она есть, сможет читать переписку.
- Если ключ скомпрометирован — удалите `config/channel.secret.yaml`,
  запустите `generate_channel.py` заново и переприменине настройку на все
  устройства через `provision_device.py`.

## Диагностика

- `python3 scripts/list_devices.py` — список USB-портов.
- `python3 scripts/list_devices.py --ble` — поиск Meshtastic-устройств по
  Bluetooth поблизости (устройство должно быть включено).
- Если `provision_device.py` зависает на подключении — проверьте, что
  порт не занят другой программой (например, открытым Serial Monitor), и
  что кабель USB-C поддерживает передачу данных, а не только зарядку.
